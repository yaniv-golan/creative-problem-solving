Use the `creative-problem-solving` skill on the problem below.

**Invoke the skill — do not answer from this file.** It carries the method; its
`references/pipeline.md` carries the stages, the sub-agent types, the file each one writes and
the scripts that check them. Read that reference before generating anything.

Before it starts, the run shows you the reading it settled on and asks two things: what you have
already tried or ruled out, and what would count as solved. If you do not want to be asked
anything, say so in the problem text and the run will show its reading and start.

This command exists to make invocation reliable, and for nothing else. It does not change what
runs, add a stage, or relax one. A run reached by asking for the skill by name and a run reached
by typing `/ideas` are the same run.
